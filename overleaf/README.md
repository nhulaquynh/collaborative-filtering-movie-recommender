# Biên dịch báo cáo GPL/MIT/Apache 2.0

1. Tải thư mục này lên Overleaf hoặc tạo project mới rồi upload `main.tex`.
2. Chọn **XeLaTeX** tại **Menu > Compiler**.
3. Chọn `main.tex` là Main document rồi Recompile.
4. Xuất PDF, lưu ảnh chụp màn hình biên dịch thành công trong minh chứng bài nộp.

Biên dịch cục bộ (TeX Live):

```bash
latexmk -xelatex -interaction=nonstopmode main.tex
```

Báo cáo là phân tích giấy phép nguồn mở với nguồn chính thức, không phải nghiên cứu thực nghiệm. Hoàn thiện tên tác giả trước khi nộp.
